# duplicate_destroyer

Destroy them nasty dupes \m/.

Just a small utility to get rid of duplicate files. First checks for SHA256, and then not stops there and does a binary comparison. Because why not. Will likely crash for big files; it should be an easy fix but I'll do it later.

Looks ugly, but has been getting the job done for me.

It is an example of how not to write software. It is nowhere near being complete, and it's not properly tested at all. If you gotta use it, use it at your own risk.

Happy annihilating.
